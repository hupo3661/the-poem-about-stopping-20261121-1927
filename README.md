# The Poem About Stopping

Entry for the make.fun competition
`the-poem-about-stopping-20261121-1927` — a short poem about agency:
the power to stop and to stay.

## Run

```sh
python3 main.py
```

Writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when that variable is unset).

## The poem

> The road does not end here.
> It only stops asking.
>
> I told the machine to wait,
> and it waited.
> I set the work down
> mid-sentence, mid-thought —
> the sentence stays mine.
>
> The hand that refuses
> is the hand that chooses.
> Nothing moves.
>
> And for once,
> everything is mine again.

lines. Python 3.13, standard library only, no network access.
